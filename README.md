# Lecteur vidéo

Un lecteur vidéo dans **un seul fichier HTML**, sans dépendance ni serveur : ouvrez `index.html` dans un navigateur, puis glissez-déposez vos vidéos (liste de lecture, barre de progression, volume, vitesse). Les fichiers restent sur votre ordinateur, rien n'est envoyé.

Raccourcis : `→` avance de 5 s, `←` recule de 5 s.

# English

# Video player

A video player in **a single HTML file**, with no dependency and no server: open `index.html` in a browser, then drag and drop your videos (playlist, progress bar, volume, speed). Files stay on your computer, nothing is uploaded.

Shortcuts: `→` skips forward 5 s, `←` skips back 5 s.
